# SW-HB-SEN-025 — Natural Senion Evidential Cheat Sheet

## Normal evidentials

```txt
-nai     seen / directly witnessed
-nal     heard, felt, smelled, sensed
-thur    inferred from evidence
-mar     assumed from habit or general knowledge
-kel     reported / hearsay
-sai     directly quoted
-seln    written or recorded source
```

## Not evidentials

```txt
-vor     sealed/restricted mood
-ha      topic marker
-ren     past tense
-thel    future tense
-lan     plural
```

## Everyday examples

```txt
Kor han-nai.
Door exists. I see it.

Sūn han-nal.
Sound exists. I hear it.

Kor morh-ren-thur.
Door opened, apparently.

Torhul morh-thel-mar.
Office will open, as expected.

Kor morh-ren-kel.
Door opened, I’m told.

Kor morh-ren-sai.
“Door opened,” as quoted.

Kor morh-ren-seln.
Door opened, according to the record.
```

## Stillwater rule

Senion marks source.

Stillwater treats source as authority.

That institutional misunderstanding is useful lore.
