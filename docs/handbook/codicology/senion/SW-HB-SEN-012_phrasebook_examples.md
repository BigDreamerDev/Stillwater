# SW-HB-SEN-012 — Senion Phrasebook and Example Texts

Use these as templates for ARG files.

---

## Minimal Sentences

| Senion | English |
|---|---|
| `Ya osh-nai.` | I witnessed it. |
| `Kor han-nai.` | The door exists. I saw it. |
| `Kor han-kel.` | The door exists. I heard/read it reported. |
| `Kor han-thur.` | The door exists. I infer it. |
| `Kor han-seln.` | The door exists. The record says so. |
| `Sel han-seln.` | Silence exists. The record says so. |
| `Sūn han-kel.` | Sound exists. It was heard/reported. |
| `Arvel morh-ren-seln.` | The archive opened. The record says so. |

---

## Codicology / Archive Lines

```txt
Arvelhand kelh-ren ravelom-seln.
The archive-keeper recorded the case file. [from record]

Dakelom-ha, meren han-thur.
As for the index card, a name exists. [inferred]

Retom arvel-eth han-kel.
The returned box is in the archive. [reported]

Folan dū han-seln.
Two pages exist. [from record]
```

---

## Audio / Switchboard Lines

```txt
Sūn morh-sūn-ul-aru kelh-kel.
A signal speaks from the switchboard. [reported/heard]

Sūnom dūsendū han-vor-seln.
Audio record fourteen exists. [sealed; from record]

Nalh-ha, thuri-vor-thur.
As for listening, understand it. [sealed; inferred]
```

---

## Liminal / SCP Style Lines

```txt
Rūmven han-thur.
An unlisted room exists. [inferred]

Shavven torh-tor han-nai.
The unlisted chair is beside the desk. [witnessed]

Mirglass-ha, osh unhan-thur.
As for the mirror glass, witnessing does not exist. [inferred]

Unmal han-vor-seln.
A not-room exists. [sealed; from record]
```

---

## Longer Sample

```txt
Arvelul-ha, sel han-seln.
Ya thuri-ren kelh arvel-eth-seln.
Korven han-thur.
Na pareth-thel kor-toh-thur.
```

Translation:

```txt
As for the archive room, silence exists. [from record]
I read the record in the archive. [from record]
A false door exists. [inferred]
You will enter toward the door. [inferred]
```
