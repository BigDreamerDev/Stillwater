# SW-HB-SEN-023 — Script and Romanisation Notes

This is not a font file. It is the design brief for the Senion script.

---

## 1. Romanisation

Use romanised Senion in most repo documents until players have learned the language.

Consonants:

```txt
p t k
b d g
m n ng
s sh th
l r h
y w
```

Vowels:

```txt
a e i o u
ā ē ī ō ū
```

`ng`, `sh`, and `th` are single consonants.

---

## 2. Script Design Sources

The script should feel like a constructed archive script, not a direct copy.

| Function | Visual Source |
|---|---|
| Consonant glyph structure | Tifinagh-like geometric primitives |
| Vowel signs | Devanagari-like marks above consonants, without headstroke |
| Word separator | Greek interpunct-style midline dot |
| Sentence terminator | Devanagari danda-style vertical bar |
| Numerals | Reduced cuneiform-like wedge marks, base-six |

---

## 3. Writing Direction

Text runs left-to-right.

Words are separated by a midline dot.

Sentences close with a vertical bar.

Example layout:

```txt
YA · KOR · ARVEL-ETH · OSH-NAI |
```

---

## 4. Diacritics

| Mark | Meaning |
|---|---|
| dot above vowel | primary stress |
| horizontal bar above vowel | long vowel |
| small open circle below evidential | marks evidential clitic |

The open circle beneath evidentials is useful for puzzles because it lets players spot evidential endings visually before they know the language.
