# SW-HB-SEN-011 — How to Write in Senion

This is the practical author guide for creating new clues, records, or inscriptions.

---

## 1. Start in Plain English

Write the exact English first.

```txt
The archive opened below the seventh room.
```

Then reduce it to simple clauses.

```txt
The archive opened.
It was below room seven.
```

Senion works best with short clauses.

---

## 2. Remove Articles

Remove “a”, “an”, and “the”.

```txt
archive opened
it was below room seven
```

---

## 3. Choose Evidentials

Ask: how does the document know?

| English clue type | Senion evidential |
|---|---|
| Seen in a video/image | `-nai` |
| Heard in audio / phone call / report | `-kel` |
| Must be deduced by players | `-thur` |
| Found in handbook / official record | `-seln` |

This is not decoration. It tells players how to approach the clue.

---

## 4. Convert the Sentence

English:

```txt
The archive opened.
```

Senion:

```txt
Arvel morh-ren-seln.
Archive open-past-[from record].
```

English:

```txt
The archive is below room seven.
```

Senion:

```txt
Arvel rūm senen-bel han-seln.
Archive room seven-below exists-[from record].
```

---

## 5. Use Topic Marking for Handbook Style

```txt
Arvel-ha, morh-ren-seln.
As for the archive, it opened. [from record]

Rūm senen-ha, sel han-vor-seln.
As for room seven, silence exists. [sealed; from record]
```

---

## 6. Keep Clues Fair

A good Senion clue has at least one anchor word the player already knows.

Bad:

```txt
Terveth limenil shavven thuri-vor-thur.
```

Better:

```txt
Kor-ha, arvel-eth han-thur.
As for the door, it is in the archive. [inferred]
```

---

## 7. Use `-vor` as a Red Flag

Normal:

```txt
Kor han-seln.
The door exists. [from record]
```

Important/restricted:

```txt
Kor han-vor-seln.
The door exists. [sealed; from record]
```

---

## 8. Numbers

Senion counts in base six.

| Decimal | Senion |
|---|---|
| 1 | en |
| 2 | dū |
| 3 | thren |
| 4 | korv |
| 5 | pem |
| 6 | sen |
| 7 | senen |
| 8 | sendū |
| 9 | senthren |
| 10 | senkorv |
| 11 | senpem |
| 12 | dūsen |
| 14 | dūsendū |

For ARG readability, official identifiers can remain decimal while register prose uses Senion.

```txt
SW-AUD-014
sūnom dūsendū
```

---

## 9. Translation Workflow

```txt
1. Write clear English.
2. Split long ideas into short clauses.
3. Remove articles.
4. Replace prepositions with postpositions.
5. Add tense only if needed.
6. Choose evidential.
7. Add -vor only if restricted.
8. Check every declarative clause ends in -nai, -kel, -thur, or -seln.
```

---

## 10. Authoring Levels

| Stage | What players see |
|---|---|
| 1 | English text with repeated Senion terms |
| 2 | Senion sentences with English gloss nearby |
| 3 | Senion without gloss, but with familiar vocabulary |
| 4 | Senion in custom script with romanisation elsewhere |
| 5 | Damaged custom script only |
| 6 | Senion grammar becomes part of the puzzle logic |
