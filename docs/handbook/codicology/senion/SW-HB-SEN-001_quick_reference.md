# SW-HB-SEN-001 — Senion Quick Reference

```txt
Word order: Subject – Verb – Object
Articles: none
Plural: -lan only when needed
Past: -ren
Future: -thel
Sealed: -vor before evidential
Topic: -ha
```

## Evidentials

```txt
-nai    witnessed
-kel    reported/heard
-thur   inferred
-seln   from handbook/record
```

## Postpositions

```txt
X-eth      in X
X-toh      to/toward X
X-aru      from X
X-en       of X
X-bel      below X
X-tor      beside X
X-mar      through X
X-dor      with X
X-vesh     without X
```

## Examples

```txt
Kor han-seln.
Door exists. [from record]

Arvelul-ha, sel han-seln.
As for the archive room, silence exists. [from record]

Na pareth-thel kor-toh-thur.
You will enter toward the door. [inferred]

Kor han-vor-seln.
The door exists. [sealed; from record]
```
